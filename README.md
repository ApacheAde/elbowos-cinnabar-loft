# Cinnabar Loft

Full-colour Python 3 neon louver-ascent arcade for [ElbowOS](https://x.com/ElbowOS).

Steer a gold moth up a cinnabar shaft. Sliding louvers open a moving gap.
Clear a slat for combo heat. Clip a blade and the thermal drops.
A / D (or arrows) drift left and right.

## Play

```
pip install -r requirements.txt
python3 cinnabar_loft.py --play
```

## Record a 9:16 reel

```
python3 cinnabar_loft.py --record
```
